# تَثَبُّت · Tathabbut

**المنظومة الذكية للتحقق الفوري من صحة النصوص الإسلامية وتخريجها**

تحقق فوري من الأحاديث والآيات المتداولة: يُلصق المنشور كما هو (أو تُرفع لقطة الشاشة)، فتُستخرج النصوص المنسوبة، ويُعرض لكل نص مصدره وحكمه **منسوباً إلى قائله** — للدعاة والمعرّفين بالإسلام ومشرفي المحتوى الدعوي.

> مشروع مشارك في **تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026** — المسار الرابع: أدوات المعرفة والتحقق لتمكين المعرفين بالإسلام.

> ⚠️ أداة مدعومة بالذكاء الاصطناعي. لا تُصدر فتاوى، ولا تجتهد في الحكم على الأحاديث؛ تنقل أحكام أهل الاختصاص بنصها، وتحيل إلى المختص عند غياب المرجع.

## المبدأ الجوهري
النموذج اللغوي يستخرج النصوص ويطابقها فقط؛ أما **العزو والحكم فيُقرآن من المصادر المعتمدة** ولا يولّدهما النموذج — وفق قاعدة الحزمة العلمية للتحدي: «لا يُنسب حديث دون مصدر وحكم معتمد».

## التشغيل محلياً
```bash
npm install
cp .env.example .env.local   # ثم املأ المفاتيح
npm run dev                  # http://localhost:3000
npm test                     # الاختبارات
```
مخطط قاعدة البيانات: `supabase/migrations/`.

## المصادر
| المجال | المصدر | الاستخدام |
|---|---|---|
| الحديث وأحكامه | [الدرر السنية](https://dorar.net) — الواجهة العامة `dorar_api.json` | البحث وجلب أحكام المحدثين بنصها، مع تخزين مؤقت لما سُئل عنه فقط. لا نقوم بجمع شامل لبياناتهم. نستخدم خدمة API الرسمية وفق ما بيّنه الدرر في [صفحة الخدمة](https://dorar.net/article/389/%D8%AE%D8%AF%D9%85%D8%A9-%D9%88%D8%A7%D8%AC%D9%87%D8%A9-%D8%A7%D9%84%D9%85%D9%88%D8%B3%D9%88%D8%B9%D8%A9-%D8%A7%D9%84%D8%AD%D8%AF%D9%8A%D8%AB%D9%8A%D8%A9-API)، ونَنسب كل حكم إلى الدرر السنية؛ وطلب الإذن الرسمي وتقديم الشكر مخطط لهما بعد التحدي |
| القرآن الكريم (النص) | نص مصحف حفص من [quranpedia](https://quranpedia.net) (النسخ الرسمية المُصدَّرة، دون تعديل على النص المعروض) | المطابقة والتنبيه على الآيات المنقولة بخطأ |
| القرآن الكريم (الترجمات) | quranpedia: الأردية لمحمد جوناگڑھي، والإنجليزية لهلالي-خان، وكلتاهما من إصدارات مجمع الملك فهد | عرض الترجمة المعتمدة، والتنبيه على اختلاف الترجمة المدخلة عنها |
| النصوص المتداولة | قائمة يحرّرها صاحب المشروع، معزوّة إلى المقاصد الحسنة وكشف الخفاء والسلسلة الضعيفة، بذكر الكتاب والجزء والصفحة. تُراجَع من الكتب نفسها عبر المكتبة الشاملة / تراث (مكتبتان رقميتان، والمرجع هو الكتاب) | التعرف على المتداول غير الثابت |
| المصطلحات | جدول صغير معتمد من نموذج المصطلحات الوارد في الحزمة العلمية للتحدي (مأخوذ من [موسوعة الجمهرة](https://islamic-content.com/dictionary)) | مقابلات المصطلحات في واجهة الأداة وردودها |

### مصادر مخطط لها (ما بعد التحدي)
- **ترجمات الأحاديث** (أردو وإنجليزي) من [HadeethEnc.com](https://hadeethenc.com) دون تعديل مع ذكر المصدر، وقاعدة محلية للصحيحين. الأحاديث في هذه النسخة تُعرض بالعربية مع الحكم.
- **المكتبة الشاملة**: مطابقة النص المستخرج مع الطبعات المعتمدة للكتب. غير مستخدمة في هذه النسخة.
- **التكامل الكامل مع موسوعة الجمهرة** للمصطلحات.
- مراجع أخرى من الحزمة العلمية (التفسير، الفقه العام، السيرة) عند توسيع الأداة إلى الإجابة عن الأسئلة، وهي خارج نطاق التحقق الحالي.

## إعادة الاستخدام والإفصاح
- أجزاء من مشروع سابق للمشارك نفسه، **Al-Ulama Easy Editor** (AGPL-3.0): تحليل استجابة الدرر السنية (`src/lib/dorar.ts`)، وتطبيع النص العربي ومقارنة ألفاظ المتن (`src/lib/arabic.ts`).
- مجموعة الاختبار أعدّها صاحب المشروع (متخصص في الحديث وعلومه)، وتُعلَّم إجاباتها قبل تشغيل الأداة عليها.
- بدأ التجهيز والتطوير قبل 4 أكتوبر 2026 بإذن إدارة التحدي («البدء بتجهيز الفكرة والتطوير من الان مع اكمال العمل يوم ٤ اكتوبر»)، ويُظهر سجل الإيداعات في هذا المستودع تاريخ كل جزء.
